# Dotcreative_Blog
 Blog Page for Dotcreative using WP as headless CMS

Setup
Clone the code

npm install --legacy-peer-deps

npm run dev

The blog page /blog


WordPress Access

URL	https://blog.dotcreative.co.ke/wp-admin

REST API	https://blog.dotcreative.co.ke/wp-json/wp/v2/posts

(Credentials are not stored in this repo — use your local/secure store.)



Fix any remaining errors that might appear
